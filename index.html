Introduction to CompTIA A+ Classification

Your entry-level professional launchpad into computer hardware architectures, operating system environments, security, and fundamental technical operations.

Dual-Exam Mastery

CompTIA A+ covers two distinct exam domains. Core 1 (220-1101) examines physical motherboards, RAM modules, processors, networks, and mobile hardware.

Systems & Operating Rules

Core 2 (220-1102) tests OS configuration capabilities (Windows, Linux, macOS), cybersecurity operations, operational scripting, and cloud configurations.

Industry Recognition

Highly respected by industry leaders worldwide. It qualifies technicians for key roles in hardware maintenance, IT support, network administration, and client infrastructure tasks.

Exam Objectives Alignment

Exam 220-1101 (Core 1) Focus

  • Mobile Devices (15%): Laptop configurations, hardware installation, accessories.
  • Networking (20%): Protocols, TCP/UDP sockets, physical cables, network devices, and configurations.
  • Hardware (25%): Processors, CPU sockets, RAM topologies, M.2/SATA drives, and power supplies.
  • Virtualization & Cloud (11%): Hypervisor architectures, SaaS, PaaS, IaaS.
  • Network Troubleshooting (29%): System post codes, network fault diagnostics, storage failures.

Exam 220-1102 (Core 2) Focus

  • Operating Systems (31%): Active Directory, command-line syntax, system optimization.
  • Security (25%): Malware prevention, access permissions, social engineering tactics.
  • Software Troubleshooting (22%): Application failures, mobile OS configurations, decryption steps.
  • Operational Procedures (22%): ESD controls, communication protocols, licensing standards, and disaster recovery.
